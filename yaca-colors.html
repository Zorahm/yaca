Yaca — Цветовая схема

Простой HTML-файл, построенный по фирменным цветам Yaca.

#1E3A5F — основной синий
#93C5FD — светло-голубой
#ffffff — белый
#0f172a — тёмно-серый

Цвета

Основные цвета Yaca:

  • Синий (#1E3A5F) — основной цвет интерфейса
  • Светло-голубой (#93C5FD) — акценты и подсветка
  • Белый (#ffffff) — фон для контраста
  • Тёмно-серый (#0f172a) — темные элементы

Пример кода

// Yaca color scheme example
const primary = '#1E3A5F';
const accent = '#93C5FD';
console.log(primary, accent);
